## 📂 Highlighted Projects

### 💳 [Fraud Detection Pipeline](https://github.com/kashyap0612/Fraud-Detection-Pipeline)
* **Stack**: Python, Pandas, Scikit-learn, XGBoost, FastAPI
* End-to-end transaction fraud classifier trained on 590K+ records (IEEE-CIS data) with optimized datatype sizes to manage memory.
* Tuned the probability decision boundaries to secure **91% Recall** and **0.97 ROC-AUC**.
* Exposes a FastAPI inference web server that performs real-time classification in **under 135 ms** per request.

### 🖼️ [AutoDataset: Image Curation Platform](https://github.com/kashyap0612/AutoDataset)
* **Stack**: FastAPI, Playwright, Supabase, OpenAI CLIP
* Automated out-of-distribution (OOD) image compiler that extracts authentic dataset testing media directly from Google/Web crawler engines.
* Captures and filters raw images utilizing Playwright, weeding out UI elements and low-resolution assets (<2KB).
* Employs zero-shot categorization through CLIP models, isolating target classes from noisy backgrounds with **95%+ accuracy**.

### 📱 [Edge DL Conversion & Quantization Pipeline](https://github.com/kashyap0612/Edge-DL-Conversion-Pipeline)
* **Stack**: Python, PyTorch, ONNX, TensorFlow Lite, Android
* Built an optimization flow converting heavy PyTorch models (MobileNetV2) into deployment-ready, highly compressed 16-bit and 32-bit TFLite formats.
* Validates and repairs computational graph nodes using ONNX intermediate representations.
* Integrates a test bench assessing edge execution times directly on mobile/Android devices.
